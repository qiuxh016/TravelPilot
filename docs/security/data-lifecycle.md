# 数据生命周期与保留期限决策草案

状态：供首发产品决策和隐私说明使用。以下建议期限未获最终确认，也没有由此启用数据库定时清理、备份过期或日志生命周期规则。部署前需确定实际期限、执行者和用户可见说明。

## 当前已实现行为

- 用户可导出账户 JSON，也可删除账户。删除账户会使数据库中的账户、旅行及关联数据按级联关系删除，并尝试删除该账户的动态原图和缩略图。
- 删除账户时，仍被其他记录引用的 POI 会保留；已无 Wishlist/Plan 引用的手工 POI 会清理。Provider POI 属于共享地点目录，不随单个账户删除。
- 账户删除不代表既有数据库备份中的副本立即消失。当前开发数据库已完成一次隔离容器恢复演练；生产异地备份、保留策略和自动销毁尚未配置和验收。
- 验证邮箱令牌有效 24 小时，密码重置令牌有效 1 小时，均只能使用一次。Worker 启动时及之后每小时清理过期会话、过期邮件令牌、已消费超过 24 小时的邮件令牌，以及登录窗口结束超过 24 小时且未处于锁定期的失败计数。清理依赖 Worker 持续运行；启动失败会记录不含用户标识的错误类别，任务处理继续。
- Redis 限流计数和邮件发送预算为短期控制数据；应用日志记录请求 ID、方法、路由模板、状态码和耗时，不记录请求正文、邮箱或动态路径值。
- 动态图片上传时会重新编码并移除 EXIF 等图片元数据。外部模型或 Provider 的数据处理与保留以最终选定服务的条款和配置为准，当前未建立供应商侧删除保证。

## 建议期限（待确认）

| 数据类别 | 当前用途 | 建议保留规则 | 删除/到期处理 |
|---|---|---|---|
| 账户、Trip、计划、Wishlist、旅行记忆、导入内容、动态与互动 | 提供用户保存的旅行和社交功能 | 用户主动删除前保留 | 用户删除账户时在线主库立即级联删除；对象存储同步删除，失败进入安全重试队列并告警 |
| 账户会话 | 认证与会话撤销 | 最长 12 小时，登出、重置密码或删号时提前撤销 | Worker 启动及每小时清理过期会话 |
| 验证/重置令牌 | 邮箱验证和密码重置 | 按功能期限：验证 24 小时、重置 1 小时；已消费记录额外保留 24 小时 | Worker 启动及每小时清理到期/已消费记录 |
| 登录失败计数 | 暴力尝试限制 | 登录窗口结束 24 小时后删除；仍在锁定期的记录保留到解锁 | Worker 启动及每小时清理符合期限的记录 |
| Redis 限流计数/邮件预算 | 短时反滥用和成本控制 | 由键 TTL / 滚动窗口决定，最长不超过 1 小时（建议） | 到期自动失效；不得用于画像或长期审计 |
| 应用与安全事件日志 | 故障排查、滥用检测 | 建议 30 天；如需延长应给出安全/运营理由 | 日志平台自动过期；不复制用户内容、凭证或完整 IP |
| 数据库和对象存储备份 | 灾难恢复 | 建议每日备份、保留 30 天；上线前按成本与恢复目标确认 | 到期自动销毁；账户删除后的备份副本最迟在备份保留期限结束时过期，并在隐私说明中明确 |
| 地图 Provider POI 目录 | 公共地点查询和计划引用 | 按 Provider 条款与缓存策略保留；用户删除不触发全局删除 | 按 Provider 许可、数据新鲜度和无引用清理策略维护 |

建议先采用“用户内容由用户控制、在线数据删号即清、日志 30 天、备份最多 30 天”的首发基线。备份周期与保留上限必须一起确认；若平台能力或费用不支持，应在隐私说明中写明实际值，不能把建议值描述为已执行。

## 需要在开放注册前定稿

1. 确认日志和备份保留周期，以及适用的地域、加密、访问权限和销毁证明方式。
2. 选定对象存储后配置生命周期规则，并验证删号时原图、缩略图和失败重试的清理结果。
3. 监控 `/ready/worker` 是否持续返回 ready；认证记录清理已随 Worker 启动并每小时执行，清理结果只记录类别与数量，不记录用户标识。
4. 明确账号删除对好友关系、好友互动、旅行动态评论/反应和共享地点引用的逐项处理规则，并验证删除脚本与导出范围一致。
5. 列出会接收用户数据的邮件、地图、天气和模型服务，说明发送字段、服务商留存控制和删除请求边界。
6. 在隐私说明中区分在线主数据的删除时间、异步对象删除时间，以及备份副本自然过期时间。

## 验收条件

- 账户导出覆盖用户账户、旅行、计划、导入、记忆、动态和社交互动数据，并明确不导出其他用户的私有内容。
- 删除账户后，API 无法再认证该用户；主库关联行和媒体对象按定稿规则清除，其他用户仍引用的共享地点按规则保留。
- 备份恢复演练证明备份可用，同时验证备份过期策略与删号说明一致。
- 日志样例不含密码、令牌、邮箱、IP 原文、旅行正文或完整媒体 URL；安全事件能按请求 ID 关联排查。
