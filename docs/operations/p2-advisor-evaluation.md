固定场景用于回归顾问的边界行为。真实模型样本只用于观察表达质量；是否保存、地点是否有效及排程结果仍由服务端规则决定。

| A3 缺条件追问 | 新会话未提供目的地/日期 | planning state 列出缺失槽位；不能生成可确认草案 | 单测和 2026-10-17 live Playwright 均通过；无城市候选、无正式旅行 |

## 计量与运行

- API 记录模型名、提取/回复来源、阶段时长、输入/输出/总 token；普通请求日志不记录聊天正文、API Key 或图片内容。
- 顾问页使用认证后的 `/api/v1/advisor/status` 显示服务端模型配置状态、模型名和单轮输出上限；此接口不回显凭据，也不发起额外模型探测请求。实际上游错误在当轮显示并触发安全回退。
- `LLM_MAX_TOKENS_PER_TURN` 限制单轮生成 token 总额，输入提示 token 单独计量。live 浏览器用例每轮输出上限设为 1,200 token，并在完成后删除临时账户。
- live 测试显式启用：`$env:TRAVELPILOT_LIVE_LLM='1'; pnpm --dir apps/web exec playwright test e2e/advisor-live.spec.ts`。运行前确认 API 8000 使用期望的 `.env`；测试会产生模型输入费用。
- 价格随模型和供应商变更，部署前核对供应商价格表；应用目前记录 token 用量，但没有美元账单 API 或全局硬性月预算。

## 结论

已证明一次真实模型地点提取到用户确认入计划的闭环；本地回退、Schema 约束、Provider 超时、硬约束与旧计划保护有回归证据。尚不能宣称自然语言回复稳定或目的地推荐质量达标：A2、A4 的模型输出质量需要持续收集盲评样本后再决定是否扩大试用。

目的地探索首版不依赖 LLM 自由生成城市：六个固定城市按用户明确偏好最多触发 12 次地图搜索，只从非模拟 Provider 返回的 POI 构造最多三张城市卡。真实 API 和浏览器流程已通过；自动化证明调用上限、故障下的部分结果处理及证据传递。候选排序质量仍需人工标注评测；扩大用户前应核对当前 AMap Web 服务配额与价格。

推荐接口为地图额度增加了用户级 Redis 窗口限流，默认 10 分钟 3 次；生产环境限流身份由 `AUTH_RATE_LIMIT_HASH_SECRET` HMAC 保护。仍需在所选部署环境确认 Redis 可用和阈值适合 AMap 当前配额。
