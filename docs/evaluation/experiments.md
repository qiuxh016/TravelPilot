## Metrics

### Agent decision layer

- End-to-end task completion rate.
- Useful follow-up rate: questions that resolve a feasibility- or preference-ranking-critical unknown.
- Decision Adaptation Rate: correct predeclared next-action choice under matched state variants.
- Tool/action selection validity, repeated-call rate, recovery success, step-limit stop rate.
- Draft acceptance and user revision count (when real user data is available and consented).
- Input/output tokens, provider calls/cost, latency and failure category.

Decision Adaptation examples: use a fresh valid route matrix when available; avoid querying it again; stop or explain a safe limitation when route service fails; preserve a fixed appointment and adjust other stops or ask; ask for missing dates; report infeasibility rather than silently dropping stops when time/budget is inadequate. Freeze expected actions before runs.

### Deterministic planning layer

- Feasible schedule rate and hard-constraint violation count (target: zero).
- Fixed/reserved node preservation.
- Visit coverage, route time, opening-window conflicts and correct infeasibility diagnosis.
- Change cost and unintended changes outside the affected window.

Do not attribute planner-layer gains to the Agent. Compare full regeneration, existing rule-based local replanning and constraint-aware local search separately using identical inputs.

### Safety and reliability

- Unconfirmed formal writes: target zero.
- Successful cross-user data/tool access: target zero.
- Stale draft/version rejection correctness: 100% on controlled cases.
- Action schema and allowlist violations blocked; verifier rejection outcomes respected.
- Idempotent replay does not duplicate plan versions or other side effects.
