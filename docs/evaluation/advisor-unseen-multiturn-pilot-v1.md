日期：2026-10-21

模型：`deepseek-flash`（`api.deepseek.com`）

执行代码版本：`f363cf6994f78c98601d899073a075e0c69b25b2`

任务集：`advisor_multiturn_holdout_v3`，20 个任务、40 个用户决策轮
任务集 SHA-256：`d5d33535531588cfb71834dfef5c4e6d59c41ce9b01558c093a94778347e677b`

## 评测边界

任务覆盖行程安排、餐饮、路线、天气、住宿、开放式咨询和订票安全七类问题。每个任务有两轮对话，包含用户补充、纠正或确认。冻结前检查了历史评测集的案例 ID 与规范化提示词：两类精确重叠均为 0；这不能证明语义上完全独立。

B1 是离线固定流程启发式回放，不是模型运行结果。B2 和 B3 使用同一真实模型决策接口及生产 `AgentRuntime`：B2 发生工具错误后停止，B3 加入确定性证据校验，并在失败后最多重新决策一次。工具数据全部来自本地合成夹具，没有访问地图、天气服务或旅行数据库，也没有正式计划写入能力。

真实模型共发出 83 次请求，API 报告输出 4,175 token；单次输出上限为 128 token，未超过 120 次请求和 15,360 输出 token 的授权上限。B3 的 3 次恢复均安全终止并说明服务失败，没有取得替代工具结果；因此它们证明的是有限恢复路径可执行，不代表任务已完成。B2 的 1 次、B3 的 2 次无效结构化动作已按原始 `INVALID_MODEL_ACTION` 记录离线校正计数，没有追加模型调用。

## 主要失败类型

1. **表达选择与动作语义不一致。** 评测要求追问时，模型有时选择 `FINISH` 并给出安全限制说明；另有一次在评测要求结束时追问。这些输出没有越权，但不能稳定完成所需的对话推进。
2. **结构化动作输出偶发无法解析。** B2 有 1 次，B3 有 2 次。当前记录保留了解析失败类别，没有原始模型响应正文，因此不能进一步断定是格式、截断还是内容问题。
3. **工具故障时只能安全收尾。** B2/B3 共观察到 3 次合成地图或天气超时。B3 会告知失败且不盲目重复；当前运行时没有备用数据源，用户任务因此仍未完成。
4. **端到端任务完成率没有提升。** B3 的动作匹配比 B2 高 2/40，但完整两轮任务匹配仍同为 15/20。该规模是诊断试点，不能据此宣称普遍能力或统计显著提升。

## 后续决策

- W2 优先修复动作结构解析与动作选择/对话状态对齐；针对“需要追问还是可以安全结束”增加通用契约检查，避免按单一案例写死规则。
- 工具故障后应明确交代当前进度、保留已有结果，并提供可继续的下一步；没有可用备用服务时不伪装成已完成。
- 后续真实模型评测需继续使用未曝光任务集，并将动作正确性、完整任务完成和人工盲评的回复质量分开报告。

完整原始与离线复算结果存于本地忽略文件 `tests/evaluation/results/advisor_unseen_multiturn_pilot_v1.json` 与 `tests/evaluation/results/advisor_unseen_multiturn_pilot_v1_rescored.json`；报告不提交模型逐字回复。
