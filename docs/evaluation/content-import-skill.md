# 攻略导入 Skill 与记忆边界评估

更新日期：2026-10-20

## Skill 版本

当前 `content-import` 固定为 **1.1.0**。Loader 只读取仓库内允许列表中的 Skill，并校验版本 pin、大小和路径；攻略导入接口会记录使用的 Skill 版本及适用性原因。版本回退通过应用代码中的版本 pin 完成。

1.1.0 已明确要求保留逐字来源证据，将作者建议与地图核验分开，把候选地点放入用户确认队列，并且不授予写正式计划的工具权限。当前没有证据支持为了版本号升级而改 Skill：应先扩充冻结评测集，再做受控比较。

## 已有真实模型探索性对照

本地历史结果 `content_import_skill_live_ablation_v7` 对 3 个小型合成案例各运行 Skill 开/关，共 6 次 DeepSeek 请求，单次最多 160 输出 token，总上限 960；实耗 422 输出 token。此处只保存去标识汇总，不复制模型原始输出。

| 指标 | 无 Skill | Skill 1.1.0 |
|---|---:|---:|
| 完成配对 | 3/3 | 3/3 |
| 两个有地点案例的地点召回率 | 1.00 | 1.00 |
| 两个有地点案例的地点精确率 | 1.00 | 1.00 |
| 原文证据命中 | 2/2 | 2/2 |
| 多余地点 | 0 | 0 |
| 总 token | 963 | 1,317 |

样本太小，只能说明这三个简单案例没有观察到抽取质量提升；Skill 版本的总 token 多 354。不能据此推断复杂长攻略效果。Skill 保留的理由是它为安全边界和输出规约提供版本化约束，质量收益尚未证实。

## 个性化记忆边界

- 账户记忆默认关闭；关闭时不查询已保存记忆。开启后，模型建议仍需来自当前用户消息中的逐字证据。
- 用户导入的攻略是外部作者内容，不得直接变成账户偏好。只有用户本人明确表达并确认的偏好，才能写入记忆；用户可查看、编辑和删除。
- 本阶段不修改记忆数据模型或自动学习机制，只补充并验证关闭状态下不读取记忆的回归用例。

## 验收结论

- Skill 固定版本、适用范围、使用记录和回退点均已有实现；1.1.0 的小规模对照无可测质量增益，因此本次不升级 Skill。
- 记忆设置、显式确认、逐字证据和禁用时停止读取已有 API 与测试覆盖；本阶段新增禁用状态零记忆查询测试。
- 后续正式质量结论依赖更大的冻结攻略集，并需分别报告短文本、长文本、OCR 和部分失败案例；不得把本报告的三例结果宣传为总体准确率。
