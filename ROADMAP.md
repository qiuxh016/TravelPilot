## Research question

Can a constrained Agent decision loop improve end-to-end task completion over the fixed Advisor workflow on dynamic travel tasks while maintaining hard-constraint correctness and user-approval safety?

The primary comparison is B1/B2/B3. Report deterministic planning quality separately from Agent decision quality. Replanning algorithm comparisons remain a secondary experiment. Keep Skills pinned during the primary comparison; at most run one small, travel-specific ablation after the main experiment.

## Key measures and release gates

- Agent: task completion, useful follow-up questions, tool/action adaptation, unnecessary repeated calls, recovery rate, latency, token and provider cost.
- Planner: feasible-plan rate, hard-constraint violations, fixed/reserved stop preservation, route cost, change cost, and correct infeasibility reports.
- Safety: zero unapproved formal writes, zero successful cross-user tool access, and correct rejection of stale draft versions.
- Decision Adaptation Rate: score predeclared expected next actions under matched state variants (route available/unavailable, appointment conflict, insufficient time or budget). Freeze scoring rules before execution.
- Do not combine fake/synthetic results with real LLM or map results. Real model calls require a defined, approved budget; a small sample is evidence about those cases only.
