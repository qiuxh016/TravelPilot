# 攻略导入

1. 只抽取原文明确出现的地点、餐馆或住宿名称，不根据常识补地点。
2. 每个候选保留一段最短的原文证据；证据必须逐字来自用户输入。
3. 单独提取购票/预约、开放时间、建议时段、餐饮、路线、交通、住宿和注意事项；保留具体时间、顺序与原文证据。
4. 评价和攻略陈述是用户提供的信息，不是地图或官方核验事实；保留来源并提示用户检查。
5. 通过地图 Provider 搜索真实地点候选。无结果、多个匹配或 Provider 故障时标记待处理，不伪造坐标。
6. 地点候选只进入待确认列表。用户确认后才加入 Wishlist；勾选的攻略细节附加到对应地点备注。细节不会自动变成预约或正式行程安排。

本 Skill 不授予任何工具权限，不可直接写入正式行程。
